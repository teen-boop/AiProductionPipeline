# Character sheet — basic 4-view turnaround

Use for secondary/minor characters who need identity consistency but won't get heavy multi-angle
coverage. Fill in the brackets, reuse the rest verbatim.

```
Create a professional character reference sheet of the same character from multiple angles for
consistent AI generation.

Character: [age, body type, facial features, hairstyle, clothing, accessories, key details]

Layout: same character, four views, plain neutral grey studio background:
- Full Body Front (slight three-quarter, head to toe)
- Full Body Back (straight rear view)
- Front Portrait (head-and-shoulders, facial features/hair/upper clothing)
- Side Portrait (90° left profile, neck + upper shoulders)

Style & Consistency: same face, body proportions, hairstyle, outfit, colors, accessories across
all views. Preserve accurate costume details and identity in every angle. Clean balanced studio
lighting, soft shadows, realistic material textures. Sharp, high-detail, symmetrical layout.

Requirements: neutral grey background only, no text/labels/logos/watermarks/props/extra characters.
```

Attach the character's real face photo alongside this prompt for identity grounding. Once approved,
this sheet becomes an additional locked reference attached alongside the real photo and approved
hero portrait for every later generation of this character — see `05-character-lock.md`.

QC before locking in: see the "Character sheet QC" section of `08-qc-and-fixes.md`.
