# Visual story — Step 2: Script

## This project first (binding)

This skill arrives at every project knowing nothing about it. Before applying any default written below:

1. **Study this project.** Read its brief or script, every file in its references folder (images, video frames, saved prompts and their notes) and the results already approved in it. Say what you see in concrete terms before generating or writing anything.
2. **Learn from this project's results.** After each approved result, add to this project's `LESSONS.md` what was asked, the prompt or setting that produced it and why it worked; after each rejection, what failed and the fix. Read `LESSONS.md` before the next task. For this project it overrides the defaults below.
3. **Stay inside this project.** Never open, copy or imitate material from another project, brand or earlier job: no images, fonts, prompts, names or folders from elsewhere. What is missing comes from this project's own sources or from the user.
4. **Examples here are samples.** Every name, date, place or line used as an example in this skill is invented sample data. Do not carry it into the work.
5. **Improve the skill, not a memory of one project.** When a lesson would help any project, propose it to the user as a general rule with no project names in it.

**Step 2 of 5.** Before this: `visual-story-1-setup` (working folder, aspect ratio, folder
structure must already exist). After this: `visual-story-3-cast-world`.

## What this step produces

A finished, structured script or shot-list broken into numbered scenes — the thing steps 3–5
generate against. Do not start pulling references or generating images until the script exists;
references built against a half-formed script get redone.

## If the user has an idea (no finished script yet)

Run the full questionnaire → outline → synopsis → final story flow, and use the chosen structure's
beats throughout. Structures, the strict order of operations, and the verbatim operating
prompts (master combined prompt + one per structure: Save the Cat, Hero's Journey, Three-Act,
Sequence Approach) are all in `references/script-structures.md`. Read it before running this phase.

## If the user already has a script

Work from it directly — skip the questionnaire, but read the whole script before moving on so scenes
and beats can be extracted accurately in step 3.

## Break the finished script into numbered scenes

However the script arrives, end this step with it segmented into numbered scenes/mini-scenes
(`[01]`, `[02]`, ...), each with its own short prompt/description. That numbering is what steps 3–5
key off of — `Scene_01_v1/`, the reference-extraction pass, etc.

## When done

Finished script exists, segmented into numbered scenes. **Next: `visual-story-3-cast-world` — build
the character/location/prop reference sheets before generating any actual scene.**
