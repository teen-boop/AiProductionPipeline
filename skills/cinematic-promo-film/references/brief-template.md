# Brief template - cinematic promo film

Copy this into `00_BRIEF/BRIEF.md` and fill it from the conversation. Ask only for the missing fields, in one grouped
message, ordered by how much they change the film (feeling and claim first, file formats last). Quote the client
verbatim wherever the field says "in their words". Leave a field as `unknown` rather than guessing.

```
status: draft            # draft | approved (set only after the user says so)
version: 1
```

## 1. The one-sentence test

> A **<length>** film that makes **<audience>** feel **<one feeling>** about **<product / brand / event>**,
> ending on **"<the claim, in the client's words>"**.

If this sentence cannot be written, the brief is not ready. Go back to the client with the gap, not with options.

## 4. The core

| Field | Answer |
|-------|--------|
| ONE feeling (single word or short phrase) | |
| ONE claim (in the client's words, quoted) | |

Rules: one feeling, not three. One claim, not a feature list. If the client gives five claims, ask which one they would
keep if the film could only say one thing; the rest can live in the share copy.

Typical banned items to ask about: competitor shapes or colours, specific words, unsafe use of the product, people in
roles the brand avoids, looks the client already rejected (flat grey, glossy "AI poster", neon SaaS gradients).
