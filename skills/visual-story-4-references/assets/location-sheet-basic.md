# Location sheet — basic 4-angle turnaround

Same discipline as `character-sheet-basic.md`, applied to a location instead of a person. Use for
any location that will be reused across more than one scene. Fill in the brackets, reuse the rest
verbatim.

```
Create a professional location reference sheet of the same environment from multiple angles for
consistent AI generation.

Location: [architecture, wall/floor colors and materials, key furniture and fixed decor, lighting
sources, era/style, any fixed props that are part of the room itself (not character-carried props)]

Layout: same location, four views, no people or characters in any panel:
- Wide Establishing (the location's main/default camera angle, full space visible)
- Reverse Angle (looking back from roughly the opposite side of the room/space)
- Detail / Feature Close-up (a key architectural or decor element that recurs in scene coverage —
  a doorway, a fixture, a distinctive wall feature)
- Side / Alternate Angle (a 90° or corner view showing depth not visible in the establishing shot)

Style & Consistency: same wall colors, materials, furniture placement, and lighting scheme across
all four views — this is one continuous space, not four different rooms. Clean, evenly lit,
matching color grading and time-of-day light in every panel. Sharp, high-detail, symmetrical
composition per panel where the location's actual architecture is symmetrical.

Requirements: no people, no characters, no character-carried props (suitcases, held objects) —
fixed room elements only. No text/labels/logos/watermarks.
```

Once approved, this sheet becomes the location's canonical reference — attach it alongside (not
instead of) the scene's actual character-in-location shot for every later generation set in this
location. The character-in-location shot (see `09-location-and-prop-references.md` step 1) stays the
primary practical reference for actual scene generation; this turnaround sheet is what keeps the
*architecture itself* consistent when a scene needs an angle the character shot didn't establish.

QC before locking in: check panel-to-panel that wall color, furniture placement, and light source
position are the same room, not four different interpretations of the same text description — this
is the exact failure mode multi-angle references exist to catch.
