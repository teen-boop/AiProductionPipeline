# Character sheet — full production sheet

Use for leads and any character who will recur across many scenes/episodes. More coverage than the
basic 4-view sheet — catches drift that only shows up under heavier multi-angle, multi-expression
use.

```
Create a professional, high-detail character reference sheet of the same character for consistent
AI generation across an entire production.

Character: [age, body type, facial features, hairstyle, clothing (full detail: fabric, color,
fit, wear/damage state), accessories, distinguishing marks (scars, tattoos, etc.), key details]

Layout: same character, plain neutral grey studio background, panels:
- Full Body Front (head to toe, relaxed stance)
- Full Body Back (straight rear view)
- Full Body 3/4 (three-quarter angle, head to toe)
- Front Portrait (head-and-shoulders)
- Side Portrait (90° left profile)
- Side Portrait (90° right profile)
- Close-up on hands/key prop (if the character has a signature prop or hand detail)
- Expression sheet: neutral, and 2 story-relevant expressions (e.g. wary, resolute) — same
  lighting and crop as the front portrait panel
- Colour palette: a small row of the character's key costume/skin/hair colours as flat swatches
  (this becomes the character's entry in the Production Design Guide's palette — see
  `references/production-design-guide.md`)
- Age/state variants as their OWN labeled rows if the story needs them (e.g. YOUNG / OLD), not
  crammed into one row

Style & Consistency: identical face, body proportions, hairstyle, outfit, colors, accessories,
and any scars/marks across every panel. Preserve exact costume and identity details in every angle
and expression. Clean balanced studio lighting, soft shadows, realistic material textures. Sharp,
high-detail, symmetrical layout.

Requirements: neutral grey background only, no text/labels/logos/watermarks/props not specified
above/extra characters.
```

Attach the character's real face photo (and prior approved portrait, if one exists) alongside this
prompt. Once approved, this sheet is the primary locked reference for this character for the rest
of the project — attach it, plus the real face photo, to every subsequent generation (see
`05-character-lock.md` for attachment order).

If the character will appear in a specific recurring locked state (soaked from rain, injured,
mid-costume-change), generate a `character-sheet-state.md` variant in addition — don't try to cram
every state into this one sheet.

QC before locking in: see the "Character sheet QC" section of `08-qc-and-fixes.md`.
