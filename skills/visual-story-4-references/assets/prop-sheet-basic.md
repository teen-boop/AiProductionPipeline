# Prop sheet — basic 4-view turnaround

Same exact structure as `character-sheet-basic.md`, applied to an object instead of a person. Use
for any prop that recurs across more than one scene. Fill in the brackets, reuse the rest verbatim.

```
Create a professional prop reference sheet of the same object from multiple angles for consistent
AI generation.

Object: [material, color, size, era/style, distinguishing marks or wear, any moving parts or
components, key details that must stay identical every time it's generated]

Layout: Display the same object in four views on a plain neutral grey studio background:
- Front View: the object's main/default presentation angle, fully visible.
- Back / Reverse View: straight rear or opposite-side view.
- Detail Close-up: the single most distinguishing feature or component, tight crop.
- 3/4 Angle View: a rotated angle showing depth/form not visible in the front view.

Style & Consistency: same material, color, proportions, and wear/detail across all views. Preserve
accurate object identity in every angle. Clean, balanced studio lighting with soft shadows,
realistic material textures. Sharp, high-detail, suitable as a production design reference.

Requirements: neutral grey background only, no text/labels/logos/watermarks, no hands or people, no
other objects competing for attention in frame.
```

Attach any existing scene image showing the object (if one exists) alongside this prompt so the
sheet matches the object's already-established appearance, rather than inventing a new one. Once
approved, this sheet becomes the object's canonical reference — attach it to every later generation
that includes it, the same way an approved character portrait is attached (see
`05-character-lock.md`).

QC before locking in: same principle as character-sheet QC in `08-qc-and-fixes.md` — check
panel-to-panel that it's the same object, not four different interpretations of the same
description.
